# AssemblyAI Agent Bench

**Independent project, not affiliated with AssemblyAI.**

How well does Claude Code write AssemblyAI integrations, and do AssemblyAI's recommended agent setups (docs pin, docs MCP server, official skill) actually help?

This bench runs Claude Code headless on real AssemblyAI coding tasks under several setups, then grades every run by running the generated code and asking the AssemblyAI API what really happened, never by trusting the agent's own summary.

Status: work in progress. Results and how to run it are coming.
